# 오운완 다이어리

운동하면 관리자가 승인하고, 포인트가 쌓이면 랜덤박스로 쿠폰(게임하기권, 방송하기권, 연차 데이트권)을 뽑는 둘만의 운동 앱.
휴대폰 홈 화면에 추가해서 앱처럼 쓰는 PWA예요.

## 저장 방식

- **클라우드 모드**: `.env`에 Supabase 정보가 있으면 두 휴대폰이 같은 데이터를 실시간으로 봐요. 설정 방법은 [docs/SUPABASE.md](docs/SUPABASE.md)
- **임시 모드**: `.env`가 없으면 이 기기 브라우저에만 저장되고, 비밀번호는 아무 6자리나 통과해요. 화면 테스트용이에요.

## 기능

| 화면 | 기능 |
|---|---|
| 로그인 | 운동러(돼지) / 관리자(신) 고르기 + 비밀번호 4자리 |
| 오늘 | 날짜별 운동, 동작 체크, 자세 설명과 유튜브 영상, 완료 요청(사진·한마디) |
| 캘린더 | 11월·12월 계획, 근무 코드, 완료 도장, 날짜 눌러서 자세히 보기 |
| 상점 | 랜덤박스 30P, 흔들리는 연출, 10번째 레어 이상 확정 |
| 쿠폰함 | 보유 / 요청 중 / 사용 완료, 날짜 정해서 사용 요청 |
| 관리자 | 운동 승인·반려 + 한마디, 쿠폰 사용 수락, 포인트 직접 지급, 내역 |

포인트 규칙: 운동 승인 +10P, 한 주(일~토)에 3번 승인되면 보너스 +10P, 박스 1회 30P.
확률: 일반 60% (게임 30분 45 · 꽝 15) / 레어 30% (방송 15 · 게임 2시간 15) / 전설 10% (연차 데이트) — `src/data/rewards.ts`

## 실행

```bash
npm install
npm run dev
```

특정 날짜로 보고 싶으면 주소 뒤에 `?today=2026-12-16` 처럼 붙이면 돼요.

## 폴더

```
src/
  data/plan.ts       12월 운동 캘린더 (PDF 내용)
  data/routines.ts   동작·무게·자세 설명·영상 검색어, 기간별 횟수
  data/rewards.ts    상점 보상과 확률
  lib/store.tsx      데이터 저장 (cloudBackend = Supabase, localBackend = 임시 모드)
  screens/           로그인, 오늘, 캘린더, 상점, 쿠폰함, 관리자
  components/        아이콘, 돼지/신 그림, 하루 운동 카드
supabase/schema.sql  DB 테이블·권한·함수 (승인, 박스 열기, 쿠폰)
supabase/accounts.sql 두 계정에 역할 붙이기
public/images/       로그인 사진
```
